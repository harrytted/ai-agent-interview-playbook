# Agent 基础原理

<div id="agent-基础课程"></div>

**从概念和运行机制讲起，结合图解、案例与实验理解 Agent。**

学习 Agent，可以先抓住几条关系：模型怎样理解输入并作出决定，工具怎样把决定变成外部行动，记忆怎样为下一步提供信息，规划又怎样组织一连串行动。本手册先把这些概念讲清，再逐步深入上下文、检索、评测与工程实现。

从 [01 · Agent 的组成与协作](01-system-map.md)开始，按基础原理的十章顺序连续学习。每章都在本页完整讲解概念、机制、图解与案例，不要求先跳到面试题。你可以只阅读，不需要先准备Python环境；需要看实现或复算时，再补函数、字典、JSON和向量基础。

## 在知识体系中找到位置

[知识主线与阅读顺序](knowledge-map.md)把十章基础与十二章进阶接起来。第01章的组件总览先建立直觉：模型机制在02展开，当前输入在03展开，工具循环在04展开，工具接口、RAG、记忆和规划在05–08各讲一层。09–10再回答怎样评估质量、处理故障与安全问题。

贯穿例子是内部政策助手。正文用它解释为什么需要某种能力；想亲手验证时，再选做 [00 首次任务](00-first-agent.md)与 [政策实验](../examples/policy_agent/README.md)。

<div id="在课程中学懂再用题目检查"></div>

**先理解概念，再看它怎样运行，最后用例子检验。** 各章先解释主题是什么、为什么需要它，再沿配图和案例理解信息怎样流动。关键定义和结论用粗体标出；遇到陌生缩写，可以在首次使用处读到中文解释，或回查术语表。

读完后合上正文，用自己的话把关系串起来。例如不能只说“记忆分短期和长期”，还应解释“资料已经存着，为什么模型这一轮未必看得见”。最后再用章末关联面试题练口述与追问。已有基础、只想查漏时，也可以直接进入 [独立题目文章](../questions/README.md)。

## 三组可以亲手运行的实验

阅读本身不需要安装软件；脚本需要 Python 3.10+，仅标准库、无密钥、无网络。在仓库根目录运行：

```bash
# 同一政策案例：查询、澄清、旧证据、独立评分
python3 -m examples.policy_agent eval --suite pilot --mode offline --output .local/policy_agent/pilot-report.json

# 手工数值：Attention、余弦、RRF、检索指标
python3 examples/foundations/math_lab.py --section all

# 行动边界：正常读取、有限重试、批准/拒绝写入、循环终止
python3 examples/agent_lab/lab.py --scenario all
```

[政策实验](../examples/policy_agent/README.md)读取真实工具观察来决定下一步，并保存跨命令状态；这里的策略是有限规则。另两组为 [数学机制实验](../examples/foundations/README.md)，没有模型或语义向量生成；以及 [执行器实验](../examples/agent_lab/README.md)，用固定脚本替代模型决策。它们分别验证观察驱动规则、数值定义和执行合同。真实模型的理解、规划与工具选择需要另做实际调用评测。

## 建议的四周节奏

| 阶段 | 阅读 | 验收 |
| --- | --- | --- |
| 第 1 周 | 01–03 | 画系统图、手算 Attention、制作上下文包 |
| 第 2 周 | 04–06 | 读 trace、写工具合同、融合两份检索排名 |
| 第 3 周 | 07–08 | 管理记忆版本、设计依赖图、说明协作成本 |

可按现有基础调整学习节奏。已有基础时可从自检开始，有缺口再回读。

## 参考资料与进阶学习

遇到陌生术语，可随手查 [AI 编程字典](https://agent.harrylab.cn/dictionary/)；想换一种图解或工程案例继续理解，可访问作者的 [Agent 技术博客](https://agent.harrylab.cn/articles/)。按当前问题选读，再回对应章节做练习，知识会更容易接上。

各章正文附有官方文档、协议和原论文，集中索引见 [基础原理参考资料](verification.md)。外部课程的章节选择、依赖环境和阅读顺序见 [学习资源深度调研](../research/learning-resources.md)。

学完后进入 [工程进阶（12 章）](../advanced/README.md)，继续学习长任务 Harness、持久执行、上下文工程、Agentic RAG、多 Agent、计算机操作、性能与训练，并通过 [项目工作坊](../advanced/project-workshop.md)串成一套系统。

后续接入真实模型，可沿用 [7 天项目实验](../docs/engineering/08-project-lab.md)；需要数学、训练或推理系统更深知识时，再按 [调研报告](../research/learning-resources.md) 选修对应原课程。
