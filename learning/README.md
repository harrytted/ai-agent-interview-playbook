# Agent 基础原理

<div id="agent-基础课程"></div>

**从运行机制入门，按主题回查设计边界和排查方法。**

先从一次模型调用读起。再看如何接入工具、使用外部资料、保存进度和组织长任务。最后用评测和故障排查把这些环节串起来。

从 [01 · Agent 的组成与运行](01-system-map.md) 开始，可以连续读完十章。复习时也可以按下面的表格定位。阅读正文无需安装软件。

## 在知识体系中找到位置

[知识主线与阅读顺序](knowledge-map.md)把十章基础与十九章进阶接起来。第01章的组件总览先建立直觉：模型机制在02展开，当前输入在03展开，工具循环在04展开，工具接口、RAG、记忆和规划在05–08各讲一层。09–10再回答怎样评估质量、处理故障与安全问题。

想看一次完整执行过程，可以选做 [00 首次任务](00-first-agent.md) 或 [政策实验](../examples/policy_agent/README.md)。

## 先读到什么程度，再选做什么

阅读时重点看本轮输入、动作执行、状态变化和验收依据。第 02 章的注意力计算、第 06 章的排名融合和第 09 章的检索指标，可以在需要时结合数学实验复算。

运行实验再准备Python 3.10+，熟悉函数、字典、JSON与异常；数学实验还会用到向量、加权平均和概率。离线实验验证的是各自列明的数值或执行合同，真实模型的理解与工具选择需要另做实际调用评测。进入工程进阶后按目标选路线：接模型从13开始，SQL专题需基本查询知识，参数训练需另补概率与梯度优化基础；详见[知识主线](knowledge-map.md)。

## 三组可以亲手运行的实验

阅读本身不需要安装软件；脚本需要 Python 3.10+，仅标准库、无密钥、无网络。在仓库根目录运行：

```bash
# 同一政策案例：查询、澄清、旧证据、独立评分
python3 -m examples.policy_agent eval --suite pilot --mode offline --output .local/policy_agent/pilot-report.json

# 手工数值：Attention、余弦、RRF、检索指标
python3 examples/foundations/math_lab.py --section all

# 行动边界：正常读取、有限重试、批准/拒绝写入、循环终止
python3 examples/agent_lab/lab.py --scenario all
```

[政策实验](../examples/policy_agent/README.md)读取真实工具观察来决定下一步，并保存跨命令状态；这里的策略是有限规则。另两组为 [数学机制实验](../examples/foundations/README.md)，没有模型或语义向量生成；以及 [执行器实验](../examples/agent_lab/README.md)，用固定脚本替代模型决策。它们分别验证观察驱动规则、数值定义和执行合同。真实模型的理解、规划与工具选择需要另做实际调用评测。

## 建议的四周节奏

| 阶段 | 阅读 | 验收 |
| --- | --- | --- |
| 第 1 周 | 01–03 | 画系统图、制作上下文包；数学选做：手算 Attention |
| 第 2 周 | 04–06 | 读 trace、写工具合同、融合两份检索排名 |
| 第 3 周 | 07–08 | 管理记忆版本、设计依赖图、说明协作成本 |
| 第 4 周 | 09–10 | 定义评测集、跑故障场景、做一次项目复盘 |

复习时可以用章末配套题定位需要回读的内容。

## 参考资料与进阶学习

遇到陌生术语，可随手查 [AI 编程字典](https://agent.harrylab.cn/dictionary/)；想换一种图解或工程案例继续理解，可访问作者的 [Agent 技术博客](https://agent.harrylab.cn/articles/)。按当前问题选读，再回对应章节做练习，知识会更容易接上。

官方文档、协议和原论文集中收录在 [基础原理参考资料](verification.md)。外部课程的章节选择、依赖环境和阅读顺序见 [学习资源深度调研](../research/learning-resources.md)。

基础关系清楚后，按目标进入 [工程进阶（19 章）](../advanced/README.md)。模型接入、知识摄取与最小任务服务可以先做。长任务、协作、性能、训练、媒体交互和上线维护按需要补充。各专题可以通过[项目工作坊](../advanced/project-workshop.md)衔接，实际集成范围仍以对应实验 README 为准。

后续接入真实模型，可沿用 [7 天项目实验](../docs/engineering/08-project-lab.md)；需要数学、训练或推理系统更深知识时，再按 [调研报告](../research/learning-resources.md) 选修对应原课程。
