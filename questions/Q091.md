# Q091 GRPO 的组内相对奖励怎样计算，为什么标准化不等于完整训练？

**优先级：P1**

## 简要回答

原始 GRPO 用同题一组输出的奖励作比较基准，减少对单独价值模型的依赖。简化算例奖励 `[0,0,1,1]`，均值 0.5、总体标准差 0.5，相对值为 `[-1,-1,1,1]`。这只是相对信号，完整训练还需行为与当前策略概率、概率比、裁剪、正则和参数更新，并遵循具体实现的归一化。全组同分意味着缺少区分信号，不能推断所有损失项梯度都为零。



## 详细解析

**GRPO（Group Relative Policy Optimization，组相对策略优化）** 是一种策略优化方法。这里的**策略**由模型表示，决定给定输入下产生输出或行动的概率，**组内相对信号**比较同题各候选的奖励与组内基准。把相对值算出来，只说明训练信号的一部分已经准备好，后面仍需要实际的优化步骤。

先理解比较单位。原始设计对同一问题采样一组输出，让一条轨迹的奖励相对组内基线形成优势信号，而不是仅把绝对分数作为答案好坏标签。组内比较减少对单独价值模型的依赖，但仍需要正确奖励、可关联轨迹与行为概率。若任务初始状态或评分口径不同，分数差可能来自环境而非策略，需要把组定义与数据生成合同写清。

用一个简化算例复算：四条轨迹奖励为 `[0,0,1,1]`，均值为 0.5，使用总体标准差得到 0.5，每项减均值再除标准差，得到 `[-1,-1,1,1]`。它表示这组内部的相对位置。不同实现可能使用不同缩放、稳定项和归一化，因此示例展示计算直觉，不能把这四个数直接等同于所有框架的最终损失或完整优势实现。

真正更新参数还要知道哪些 token 是模型动作，计算相关策略概率与概率比，并结合裁剪、正则和归一化形成损失，再通过优化器更新。多次工具调用、不同输出长度和轨迹调用数都会影响信号分配。工具文本可以作为条件输入，但不能无差别参与动作目标。仅在 Python 中算出标准分，不意味着模型已经学习了任何行为。

固定旧策略 `π_old` 和优势 `A`，对同一历史、同一已采样动作计算 `r=πθ(a|h)/π_old(a|h)`，裁剪代理项为 `s=min(rA,clip(r,1-ε,1+ε)A)`；梯度下降使用其负值。取 `ε=0.2`，`(r,A)` 四种情况 `(1.4,+1)、(0.6,-1)、(0.6,+1)、(1.4,-1)` 分别得到 `s=[1.2,-0.8,0.6,-1.4]`。前两项不再奖励沿好方向扩大变化，后两项仍纠正坏方向；不能把“超出区间”一概当成无梯度。[DeepSeekMath v3 §4.1、式(3)](https://arxiv.org/html/2402.03300v3#S4.SS1)

为把整个目标算完，[训练目标实验](../examples/advanced/training-objectives.md)另取四个独立的一动作状态，已采样动作都为候选 1。旧策略概率均为 0.5，当前概率为 `[0.7,0.3,0.3,0.7]`，固定优势为 `[1,-1,1,-1]`；这不是上一段奖励的同组优势。四个代理项均值的负值为 `0.1`；参考二元分布也取 0.5，精确 `KL(当前||参考)` 均值为 `0.7 ln1.4+0.3 ln0.6≈0.082283`。本例明确最小化 `L=-mean(s)+0.1×mean(KL)≈0.108228`。

参考策略负责偏离约束，旧策略负责采样概率比，二者职责不同；本例只为手算把它们设为相同数值。每个状态的 logit 独立，用解析梯度走一步后，同一固定目标约降至 `0.098556`，并由有限差分检查梯度。它使用精确二元 KL、一动作状态均值与已给定优势，没有复现原论文按输出长度平均的采样目标、组内采样或 LLM 训练；[TRL Loss Types](https://huggingface.co/docs/trl/grpo_trainer#loss-types)也说明不同归一化需分别对齐。

同组全为零时，没有奖励差异可供这个相对项区分，但正则等其他项是否产生梯度需分别分析。应先检查任务是否过难、工具是否全失败、奖励是否只检查格式。若所有失败来自资料缺失，增加采样只会重复缺陷；若奖励可被无效引用骗过，训练可能强化投机。独立测试、奖励漏洞用例与过程证据应和分数曲线一起看。

## 常见追问

1. **总体标准差换成样本标准差数值一样吗？** 不一样。本题算例明确使用总体标准差；对齐框架时应查看实现，不能混用后声称复现。
2. **全组奖励相同就一定不更新了吗？** 只能说此相对信号没有差异；总损失可能含其他项，是否更新需检查实际计算图与优化步骤。
3. **负优势的比值高于上界，为什么仍有梯度？** 提高坏动作概率是不利方向；`min(rA,clip(r)A)` 会选择更负的 `rA`，仍纠正它。正优势超过上界、负优势低于下界才进入相应平坦段；拐点处的次梯度按实现约定。

## 实战案例

教学案例以“带引用”为奖励，四条答案都附上无效来源却全得 1 分。处理时把证据支持与格式分开，验证器独立读取来源，并增加旧版引用和正确澄清样本。验收先复算相对值，再检查无效引用不能得成功奖励；`runtime_lab.py` 只输出相对信号，新目标实验则更新独立二元小表。真实 LLM 是否更新及是否有效，仍须由对应训练运行和独立评测证明。



## 常见误区

把组内标准化称为完整 GRPO；全组同分就断言全部梯度为零；忽略策略概率与 token 归属；只看训练奖励上升而不查奖励漏洞。
