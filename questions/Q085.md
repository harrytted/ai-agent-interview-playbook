# Q085 KV / 前缀缓存与检索、工具、答案缓存有什么区别？

**优先级：P1**

先用[Q064](Q064.md)识别复用对象，再处理本题的关键路径。以下是固定串行请求的教学耗时，检索结果先进入输入，再执行模型；不是供应商实测：

| 阶段 | 基线耗时 | 仅前缀缓存命中后 |
| --- | ---: | ---: |
| 排队 | 400ms | 400ms |
| 检索 | 100ms | 100ms |
| Prefill | 600ms | 90ms |
| Decode | 900ms | 900ms |

Prefill减少85%，整次请求是否也快85%？若住宿证据已撤回，哪一种命中仍不能直接用于交付？

## 简要回答

题面总耗时从`400+100+600+900=2000ms`变为`400+100+90+900=1490ms`，节省510ms，即25.5%。KV/前缀缓存复用计算，检索/工具缓存复用业务读取，答案缓存复用交付内容，跳过的阶段不同。证据撤回后，旧检索结果或旧答案不能因命中而继续使用；当前输入仍须按有效证据与权限重建，模型计算复用另按服务合同判断。



## 详细解析

先在题面的串行路径上标明命中省掉了什么。前缀缓存只改变这里的prefill；检索仍花100ms，decode仍花900ms。若还包含模型规划、额外工具或重试，应继续加入对应路径，不能把它们藏在缓存收益之外。

阶段耗时占比限制总体收益：本题prefill只占基线30%，即使将它降为零，其他项不变时总耗时也最多减少30%。实际降低85%，因此整体降低`30%×85%=25.5%`。这组等式依赖固定串行阶段及其他耗时不变；真实服务的排队、并发和缓存竞争需要另外测量。[vLLM自动前缀缓存](https://docs.vllm.ai/en/stable/features/automatic_prefix_caching/)主要复用共享前缀计算，不能由命中率直接推导整轮加速。

选择缓存层时比较可省的关键路径、命中概率、维护开销与错误复用。长输出或前缀频繁逐出时，计算缓存收益可能有限；答案缓存可能跳过更多工作，却要求更严格的问题等价、证据与授权合同。PagedAttention处理动态KV内存组织，属于另一项优化，不能把它当作直接返回旧答案。

再为业务缓存定义合同。检索键要考虑索引、过滤、有效日期和用户可见域；工具读取要考虑参数、对象版本和新鲜度；答案还依赖问题等价性、证据和业务规则。写入结果不能随意当作可重放的读取缓存。权限在读取原始结果和复用缓存时都要成立，文本相同并不证明两位用户有相同访问范围。

验证同时看命中收益与错误复用。固定任务后比较延迟、缓存命中、证据版本和质量，注入政策更新、权限撤销与租户切换。自部署缓存配置还要考虑占用、逐出和并发；托管计费需按相应合同理解，不能由计算复用直接推导免费。缓存是减少重复工作的机制，不是绕过新鲜度与授权检查的捷径。

95%命中率可以改善均值而不改善 p99，见[缓存分布反例](../advanced/10-performance-and-serving.md#并行与高命中率为什么仍可能拖慢-p99)。缓存记录还需绑定依赖与当前权限；TTL 限制陈旧时长，不保证政策更新或撤权后立即失效，诊断时同时检查合法命中和失效误用。

## 常见追问

1. **查询字符串相同就能复用检索结果吗？** 不够，还需匹配索引、时间、过滤与可见域，或在复用前重新验证访问范围。
2. **前缀命中会提升 decode 吗？** 它主要省共享前缀处理，新 token 生成仍需计算；端到端收益取决于各阶段占比。
3. **缓存 key 带租户 ID 就完成隔离了吗？** 还要控制底层访问、更新与权限变化，检查键构造和所有复用入口，不能只靠一个字段名称。

## 实战案例

沿题面再做失效决策：性能数字不变，只把当前政策或权限条件改变。先判断复用是否合法，再比较它省了多少时间。

| 变化 | 可选动作 | 判定 |
| --- | --- | --- |
| 海岚新版住宿标准仍有效、当前权限相同 | 按合同复用有效候选/读取结果 | 仍核对日期、来源与对象 |
| 海岚新版住宿标准已撤回 | 重查受影响资料并重建答案 | 旧答案不能因耗时短继续使用 |
| 只有前缀计算命中 | 仍核对当前证据并完成新输出计算 | 命中不意味着答案已生成 |




## 常见误区

把 KV 当作完整答案缓存；认为命中就没有生成成本；只设置 TTL 不处理权限变化；把相似问题等同于可共享答案。

## 动手想一想

先复算1490ms，再将decode改为1800ms。合格答案得到新基线2900ms、命中后2390ms，仍省510ms，约17.6%；较好答案说明队列、工具和输出占比会限制整体收益。再为“命中答案后发现权限已撤回”写合法路径，不能为满足耗时预算返回旧内容；计算节省与业务可用性分别验收。
