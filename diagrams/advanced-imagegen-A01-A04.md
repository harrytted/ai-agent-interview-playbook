## A01 · 跨会话交接

Use case: scientific-educational.
Asset type: 中文 Agent 学习手册第01章的横版教材信息插画，约3:2，白底。
Primary request: 全新绘制“换会话后如何接着工作”。用真实可辨认的小物体展示工作交接，而不是矩形流程框。左边是一叠未完成研究文档和打开的文件夹，代表昨天的会话；中央是精致的蓝绿色工作包，里面露出四张不同形状的任务卡和来源文档；右边先经过放大镜核对来源与权限，再连接一份继续完成的报告。清楚的蓝绿色箭头从昨天工作流向工作包，再流向核对和继续，橙色只用于提醒重新核对。工作包保存目标、进度、证据和待办；新会话仍要检查证据与当前权限，没有任何“交接即自动授权”的暗示。
Style/medium: 高质量编辑插画，教材式信息图，轻微立体感，柔和阴影，纸张、文件夹、放大镜等实体清晰，细节精致但克制。白底，深蓝中文大字，蓝绿部件，少量橙色，视觉层级清晰，大量留白，不要SVG线框翻版。
Composition/framing: 横版约3:2；主关系从左到右；五至八个短标签，文字大到能在网页里直接读。不是带按钮的网页UI，不要把每个词都装进文字框。
Text (verbatim): 标题“换会话，工作接着做”；物体标签“昨天的会话”“交接工作包”“目标·进度·证据·待办”“核对后继续”“权限与证据仍有效”；底部短句“交接不增加权限”。除这些文字以外不增加任何可读文字。
Constraints: 中文逐字准确，箭头方向明确，交接包必须先经过核对再继续；不画人物、机器人、脑、电路装饰，不画复杂字段、代码、P17、T01，不画机械文字框，不加水印。图是教学设计示意，不虚构实测数字。

## A02 · 外部结果未知时恢复

Use case: scientific-educational.
Asset type: 中文 Agent 学习手册第02章的横版教材信息插画，约3:2，白底。
Primary request: 全新绘制“远端可能已创建工单，但回执丢失时如何恢复”。用一个远端工单档案盒、一张已经存在的工单、一张被风吹断路径的回执、以及同一枚操作凭条来表现。最显眼的是远端盒中已经有一张工单，回执在返回路上丢失，不能把超时画成远端没执行。恢复沿同一操作凭条先查询核对，分成两种结果：绿色分支找到既有工单，将已有结果收进本地记录托盘；橙色分支仍未知，指向服务合同书和对账放大镜，表示按服务合同幂等重试或继续对账。不要绘制第二张重复工单。图的核心是“先查同一意图，不因超时盲目重建”。
Style/medium: 精致编辑插画和教材信息图结合，纸张、工单档案盒、回执、凭条和放大镜有轻微立体感和柔和阴影，白底，深蓝大字，蓝绿色主体，少量橙色表示未知，不要矩形框堆叠或SVG翻版。
Composition/framing: 横版约3:2，以一个远端对象和一条丢失回执作视觉中心，下方查询核对分为找到和未知两条清楚支路，大留白，短中文标签。
Text (verbatim): 标题“超时，不代表没创建”；标签“同一操作”“远端工单”“回执丢失”“先查询核对”“找到：保存已有结果”“未知：幂等重试或对账”“按服务合同处理”。不要增加其他可读文字。
Constraints: 只有一个远端业务对象；“未知”不能箭头直连新建工单。安全重试依赖服务端幂等合同，同一标识和相同参数，不暗示本地检查点可保证外部不重复。中文准确，箭头有因果关系，不要人物、机器人、脑、电路装饰、P17、T01、JSON、代码、水印。

## A03 · 上下文筛选与回查

Use case: scientific-educational.
Asset type: 中文 Agent 学习手册第03章的横版教材信息插画，约3:2，白底。
Primary request: 全新绘制“资料先筛选，再装成当前输入”。左边是一个有很多文档的实体档案柜；中间用小型筛选台或漏斗选择少量合用文档；然后形成一个精致轻便的“当前资料包”；最右边是简洁的模型处理装置，仅用字样“模型”标识，不画脑或机器人。主箭头必须是档案库→筛选→当前资料包→模型，不允许档案柜直接连模型。长原文保留在档案柜外侧的原文托盘中，当前资料包露出一张带书签的小指针卡；用一条清楚的橙色回查路径从当前资料包返回原文，表示关键条件不清时凭指针回查。物体形态要讲机制，不能全是文字框。
Style/medium: 精致教材式信息插画，实体物件有轻微立体感、柔和阴影；白底，深蓝中文大字，蓝绿色组件，橙色只用于回查，大留白，清楚箭头。
Composition/framing: 横版约3:2，主流程左到右，下方只有一条按需回查支路，五至八个短标签；文字大而准确，不放满段落。
Text (verbatim): 标题“资料先筛选，再交给模型”；标签“档案库”“筛选”“当前资料包”“模型”“原文留存”“按指针回查”；底部短句“只放本轮所需”。除这些文字不增加任何可读文字。
Constraints: 保留“存储不直接进入模型、当前资料包才进入模型”的关系。原文仍留存，摘要或选择不能暗示删除所有原文。回查箭头可辨认，不能变成把整个档案柜塞入模型。不要人物、机器人、脑、电路装饰、P17、T01、复杂字段、代码、水印，不要SVG翻版。

## A04 · 双时间线

Use case: scientific-educational.
Asset type: 中文 Agent 学习手册第04章的横版教材信息插画，约3:2，白底。
Primary request: 全新绘制一幅一眼能看懂的“双时间线”。两条平行的实体时间轨道像精致的日历滑轨，横向日期位置严格对齐：11月1日、11月3日、11月5日。上轨是制度实际生效：新住宿标准11月1日起由600元变为700元；下轨是系统何时得知：系统直到11月5日收到通知才知道新标准，此前仍只知道600元。在11月3日用细橙色垂直标尺横跨两条轨道，连接两张放大的简短纸卡：第一张回答该日真实适用规则是700元，第二张回答系统当时只知道600元。日期是三等间隔的示意位置，11月1日上轨变蓝绿，11月5日下轨才变蓝绿，之前为柔和橙色。核心不是先后两个任务，而是同一天的“适用规则”和“当时认知”不同。
Style/medium: 精致教材信息插画，日历轨道、纸卡、通知信封有轻微立体感与柔和阴影；白底，深蓝大字，蓝绿为新标准，少量橙色为旧认知/日期标尺，克制的大留白，不是矩形流程图。
Composition/framing: 横版约3:2；上中部两条对齐时间轨道，下方两张大字纸卡，八个短标签，总文字少，不要额外说明段落。
Text (verbatim): 标题“同一天，两个时间问题”；轨道名称“制度何时生效”“系统何时得知”；日期“11月1日”“11月3日”“11月5日”；两张卡片分别写“11月3日适用：700元”“当时系统知道：600元”。不要添加其他可读文字。
Constraints: 上轨必须在11月1日切换新标准，下轨必须在11月5日才切换；11月3日两张卡必须分别是700元和600元，不可对调。图是双时间设计示意，不宣称本仓库实现了该索引。中文准确，日期位置清楚，禁止人物、机器人、脑、电路装饰、P17、T01、JSON、代码、水印，不要SVG翻版。
