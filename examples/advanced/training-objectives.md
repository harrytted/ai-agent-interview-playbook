# 训练目标小实验：目标掩码、裁剪与一次参数更新

本实验把[训练章](../../advanced/12-agent-training.md)的两类损失变成标准库计算：先用两轮动作之间夹着工具观察的轨迹计算 masked SFT，再用四个独立二元状态计算裁剪代理项与 KL。每个状态只有一个可训练 logit；没有真实分词器、Transformer、GPU、环境采样或完整 GRPO 训练器。

## 运行与核对

在仓库根目录运行，需要 Python 3，无第三方依赖，不读写持久文件或调用外部服务：

```bash
python3 examples/advanced/training_objectives.py --section sft
python3 examples/advanced/training_objectives.py --section policy
python3 -m unittest discover -s tests -p 'test_training_objectives.py' -v
```

`--section all` 一次输出两行 JSON。打印的小数是可复算数值，不是模型效果的精度或置信度；下表只保留六位便于阅读。

| 本例输出 | 手算/运行值 | 能说明什么 |
| --- | ---: | --- |
| SFT 目标数 | 4 | 只对两轮模型动作中的四个目标取均值 |
| 更新前 SFT loss | 0.748933 | `-ln(0.5×0.25×0.8×0.5)/4` |
| 更新后 SFT loss | 0.721668 | 本例固定样本上，一次解析梯度下降减少目标 |
| 更新前 policy loss | 0.100000 | `-mean([1.2,-0.8,0.6,-1.4])` |
| 更新前平均精确 KL | 0.082283 | 四个完整二元分布到参考分布的 KL |
| 更新前总目标 | 0.108228 | `policy loss + 0.1×mean KL` |
| 更新后总目标 | 0.098556 | 同一批固定样本与同一目标的一步下降 |

## 一条轨迹里的四个监督目标

教学轨迹按顺序包含：用户“询问住宿”→模型第一次动作 `[查,制度]`→工具观察 `[上限,700]`→模型第二次动作 `[未,超标]`。程序将它存成七行抽象记录，其中用户输入压成一行；这不是七个真实 token，也不能当成真实 tokenizer 的切分或合法 API 调用。四个动作符号才是本例参与监督的教学目标。

```text
目标掩码 m = [0,1,1,0,0,1,1]
目标概率   = [无,0.5,0.25,无,无,0.8,0.5]
L_SFT = -sum(m_t × ln P(正确目标_t | 已知历史_t)) / sum(m_t)
```

这里的 NLL 是负对数似然：正确目标概率越小，`-ln(p)` 越大。`masked_sft_objective` 的掩码针对目标位置；`0` 不是让模型忽略工具输入。真实模型的后续概率可以依赖工具观察，这里只把这些概率对应到独立二元小表，演示目标损失如何聚合。测试中的“改变忽略位置不改 loss”始终固定动作位置的概率，不代表改变真实上下文不会影响回答。

每个动作位置都有自己的 `z`，`p=sigmoid(z)` 表示该位置候选 1 的概率；正确标签依次为 `[1,0,1,0]`，初始 `z=[0,ln3,ln4,0]`。正确目标的四个概率因此为 `[p1,1-p2,p3,1-p4]=[0.5,0.25,0.8,0.5]`。

二元 NLL 对每个 logit 的均值梯度为 `(p-y)/4`。`sft_demo` 用学习率 0.4 更新四个参数，忽略位置没有参数更新；真实 LLM 的共享参数会同时影响多个 token，本表不模拟这种耦合。

## 裁剪代理项的合同

`bernoulli_policy_objective` 使用四个不同状态，每个状态一个已给定动作样本、独立一个 logit。所有已采样动作均为候选 1，当前概率为 `[0.7,0.3,0.3,0.7]`，旧策略概率为 `[0.5,0.5,0.5,0.5]`，固定优势为 `[1,-1,1,-1]`；这里没有从一组奖励估计优势。

```text
r_j = P_current(已采样动作_j | 状态_j) / P_old(同一动作_j | 同一状态_j)
s_j = min(r_j A_j, clip(r_j,0.8,1.2) A_j)
L_policy = -sum(s_j)/4
```

正优势且 `r>1.2`、负优势且 `r<0.8` 时代理项变平；正优势且 `r<0.8`、负优势且 `r>1.2` 仍有梯度。`clipped_surrogate` 返回代理项及其对 `r` 的导数，测试同时检查这四种情况。恰好在有拐点的边界，实验约定使用平坦侧的 0 次梯度，中心有限差分只检查可微点。

参考策略候选 1 的概率 `q_j` 全为 0.5，计算精确 `KL(current || reference)`，遍历候选 0 和 1：

```text
D_j = p_j ln(p_j/q_j) + (1-p_j) ln[(1-p_j)/(1-q_j)]
L_toy = -sum(s_j)/4 + 0.1×sum(D_j)/4
dD_j/dz_j = p_j(1-p_j)×[z_j-ln(q_j/(1-q_j))]
```

旧策略与参考策略都在更新时冻结，但职责不同；本例把二者都设成 0.5 只是便于手算。每个状态等权，`beta=0.1`、`epsilon=0.2`、学习率 0.4 都是教学参数。优势全零且 `beta>0` 时，KL 仍可能产生梯度；测试专门检查这一点。

## 与真实 GRPO 的差别

本例复算了裁剪目标结构和一次小表参数更新，没有实现同题 rollout 采样、奖励函数、组内优势估计、序列信用分配、语言模型 token 概率、批次优化、部署或泛化评测。固定损失下降只说明这次计算与参数步骤，不能推出新任务成功率提高。

DeepSeekMath v3 式(3)按同题输出及各输出长度平均，并使用其采样 KL 估计。本例按固定的一动作状态平均，KL 则精确枚举两种动作；这两点都必须随实验报告，不能把小表数值当作完整 GRPO 的复现。真实带工具轨迹还需单独规定动作 mask、观察、截断、多次调用和损失归一化的合同。

## 测试检查什么

测试既复算手工目标，也用中心有限差分 `(L(z+h)-L(z-h))/(2h)` 检查 SFT 与策略目标的解析梯度；策略检查包含候选 0 和候选 1，避开不可微边界。其他检查覆盖目标分母、忽略位置零梯度、正负优势裁剪、不利方向仍有梯度、全零优势仍有 KL 梯度，以及本例一步更新后固定目标下降。

代码拒绝全空监督目标、非法掩码、非有限数和旧/参考概率为 0 或 1 的输入，避免用未定义的比值或对数继续计算。SFT NLL 用稳定形式处理很大 logit；策略实验只使用内部概率严格处于 `(0,1)` 且比值有限的计算，不承诺极端浮点饱和时仍能表达罕见动作。

- [DeepSeekMath v3，2024-04-27，§4.1，式(3)、(4)](https://arxiv.org/html/2402.03300v3#S4.SS1)：旧/新策略比、组相对信号、裁剪与 KL；方法的原始来源。本例明确改用固定优势、一动作状态均值与精确二元 KL。
- [TRL GRPO Trainer：Loss Types](https://huggingface.co/docs/trl/grpo_trainer#loss-types)：说明不同实现可使用不同归一化；2026-11-05 核对的可变实现文档，不据它假定原始公式与所有当前默认参数相同。
